# Simple Interest Calculator

A simple Bash script application that calculates simple interest based on user inputs for Principal amount, Rate of interest per annum, and Time period in years.

## Formula
Simple Interest is calculated using the following formula:

$$\text{Simple Interest} = \frac{P \times R \times T}{100}$$

Where:
- **P** = Principal amount
- **R** = Annual interest rate (%)
- **T** = Time period (in years)
